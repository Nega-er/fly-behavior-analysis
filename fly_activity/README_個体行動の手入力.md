# 個体行動を人の手で記録するアプリ

Macは `tuji/FlyBehavior.app` で「個体行動の手入力」を選び、Windowsは `tuji/Windows_個体行動の手入力.bat` を開きます。
管理者権限なしで、Condaから分離した専用Python 3.12.10・venvと固定版ライブラリを自動で準備します。初回はインターネット接続が必要です。

## 入力を始める

既に追跡してある動画では「既存の追跡結果を使う」を押し、`tracks.csv` のある結果フォルダを選びます。
元動画が見つからない場合は、その動画を選択してください。

新しい動画では、動画・個体数（autoまたは整数）・検出条件を指定して「動画を検出して開始」を押します。
brightは明るいハエ、darkは暗いハエ、bothは背景との明暗両方の差を検出します。
容器外の反射を除きたい場合は「検出領域を選択」で範囲を指定できます。
検出とIDの対応付けには既存プログラムを使い、行動のラベルは人が入力します。

## 1秒ごとの記録

1. 「個体」のプルダウンで対象個体を選びます。
2. 開始秒を指定するか、前後の秒・次の未入力へ移動します。
3. 全体映像と対象の拡大映像を確認します。区間を開くと自動で繰り返し再生を始めます。「一時停止」で止められ、速度も変更できます。
4. 行動のプルダウン、またはボタンで代表行動を選択します。

| 行動 | キー |
|---|---|
| グルーミング頭 | 1 |
| グルーミング体 | 2 |
| 停止 | 3 |
| 前進 | 4 |
| 後退 | 5 |
| 飛んでいる | 6 |
| Unknown（判別不能） | U |

数字の入力欄やプルダウンにフォーカスがある間は、ショートカットを実行しません。
「選択後に次の秒へ」は初期状態でONです。行動を選ぶまでその区間を繰り返し再生し、記録すると次の区間を自動再生します。
最後の区間の入力後は停止します。OFFなら同じ区間を繰り返し見ながら修正できます。表の行をダブルクリックして戻ることもできます。
「未入力」を選ぶとその区間を未入力に戻します。Unknownと未入力は別に保存・表示します。

区間は `[0,1)` 秒、`[1,2)` 秒のように区切ります。最後が1秒未満の場合は実際の時間幅を使います。
1秒の間に複数の行動がある場合は、代表行動を1つ選びます。複数行動の同時入力や、頭・体の部位自動認識は行いません。

## 保存・再開・出力

記録のたびに `session.json` を保存します。保存先は画面上部に表示されます。
「入力を再開」から同じ `session.json` を開くと、入力内容と修正履歴を読み込みます。
既存結果・動画・累積学習データは変更しません。人手の行動入力も自動学習には登録しません。

「CSV・グラフを書き出す」で、入力データと同じフォルダに次を出力します。

- `manual_behavior.csv`：全個体×全1秒区間の行動、入力済みかどうか、検出されたフレームの割合、追跡区間番号。
- `manual_behavior_summary.csv`：個体ごとの行動別の合計時間と全観察時間に対する割合。
- `manual_behavior.png`：個体別の行動時系列と、行動別合計時間の積層棒グラフ。

CSVはExcelで開けるUTF-8 BOM付きです。グラフは画面の「グラフ・集計」でも確認できます。
新しい入力は `tuji/fly_activity/outputs/manual_動画名_日時/` に作成します。

## 個体番号と欠測

プルダウンの個体番号は追跡プログラムのスロット番号です。接触・重なり・欠測後に同じ生物学的個体かどうかは映像で確認してください。
拡大範囲は区間内の実際に検出できた位置から決めます。欠測したフレームに位置マーカーを補間して表示することはありません。
区間全体で検出できない場合は全体映像を表示します。対象を確かめられない区間はUnknownまたは未入力として残してください。
検出がない区間を自動で停止にしたり、未入力を停止として集計したりしません。
