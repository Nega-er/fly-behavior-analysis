# グルーミング試作：画像差分と人手判定の比較

既存の追跡座標を使い、局所的な画像変化を確認するための試作です。
固定ルールによる候補抽出であり、精度を確認済みのグルーミング分類器ではありません。
前進・後退・停止の結果は変更せず、グルーミングを別ファイルに記録します。

## 操作

- 手入力アプリで `session.json` を開き、「グルーミング試作と比較」を押すと、その入力と同じ動画・追跡を解析して比較画面を開きます。
- 自動解析の「解析結果」では「グルーミング試作を開く／実行」で、既存結果の元動画から試作を実行できます。
- 「グルーミング試作を手入力と比較」で `session.json` を選ぶこともできます。動画と追跡CSVのハッシュが一致する場合だけ比較します。
- 異なる追跡処理で付いた同じ番号を、同じ個体として扱いません。追跡が異なる場合は手入力アプリの比較ボタンを使ってください。
- 新規の自動解析では「グルーミング試作も実行」にチェックを入れると、結果の `grooming/` 内に併せて出力します。初期設定はOFFです。

個体IDごとの表、試作／人手ラベルの時系列、領域ごとの変化率を表示します。
確認動画は、最初に正解ラベルがあるID（正解がなければ最初のID）について、重心中心の画像・体軸補正後の画像・照明補正後の差分を並べます。
既存フォルダは上書きせず、別の日時のフォルダに出力します。

## 測定と判定

1. 個体を中心に画像を切り出し、重心の移動と体軸の回転を補正します。体軸の符号反転も時間方向にそろえます。
2. 胴体中心、体の周囲、体軸の両端A/Bで、フレーム差分の平均と変化画素の割合を計算します。両端A/Bは頭／体を意味しません。
3. 背景の輝度変化を差し引き、大きな照明変動・背景変動、旋回、移動との重なり、他個体の接近、欠測、体軸が不確かな場面は判定を保留します。
4. 体の周囲の変化が胴体より大きく、一定時間続く場面を候補とします。胴体・周囲とも変化が小さい場面を非グルーミングとし、その他は判定不能にします。

判定は1秒ごとにまとめます。重複して符号化された画像を独立な観測に数えず、実際に画像が更新された間隔で観測時間を計算します。
有効観測率が不足する区間は、停止や非グルーミングに置き換えません。
画面の変化率には、判定に使えないが測定できた区間も参考値として表示します。`valid_fraction` と判定理由を併せて確認してください。
羽や反射などによる局所的な動きを、固定ルールだけでグルーミングと区別できることは保証していません。

## 出力と比較用データ

| ファイル | 内容 |
|---|---|
| `grooming_frames.csv` | フレーム×IDの画像特徴、観測時間、体軸・移動の品質、候補判定と理由 |
| `grooming_intervals.csv` | 1秒区間の判定・特徴量・有効観測率・人の代表行動との比較 |
| `grooming_summary.csv` | 個体ごとの候補／非グルーミング／判定不能の時間 |
| `grooming_validation.json` | 正解付き区間の混同行列、適合率、再現率、判定できた割合 |
| `grooming_metadata.json` | 動画・追跡CSVのハッシュ、パラメータ、手入力の参照先 |
| `grooming_report.png` | 判定と人手入力の時系列、画像変化量のグラフ |
| `grooming_preview.mp4` | 補正画像・差分・人のラベルを並べた確認動画 |

頭／体の手入力をまとめて「グルーミング」、停止・前進・後退・飛んでいるを「非グルーミング」として比較します。
未入力と人がUnknownにした区間は精度の分母から外します。自動の判定不能は隠さず、グルーミングの見逃しとして再現率に含めます。
人手ラベルは1秒内の代表行動なので、フレーム単位の開始・終了の正解ではありません。

比較用特徴量と正解は `fly_activity/learning/grooming/examples/` に内容ハッシュ付きで追加保存します。
修正前の正解や過去のパラメータでの測定を消さず、既存の前進・後退モデルには自動投入しません。
この試作ではラベルを使った閾値調整・モデル学習を行っていません。今後の学習には、同一動画の近接フレームを学習用と評価用に分けない検証が必要です。
CSV・JSON・グラフと比較用教師は既存の起動時Git同期の対象です。確認動画と切出し画像は送信しません。

## 2026年10月16日の既存データでの試行

手入力済みの2動画、合計9区間（グルーミング体6、停止3）で比較しました。
最新の試作パラメータで、グルーミング候補3区間のうち正解と一致したのは1区間、停止の誤検出が2区間、判定不能が6区間でした。
この小標本での候補の適合率は1/3、判定不能を見逃しに含めた再現率は1/6です。汎用的な精度の推定値ではありません。

体軸が不確かな個体や、容器の縁の反射がある場面で判定を保留しました。
測定できた画像変化には停止とグルーミングの重なりがあり、今回の固定ルールをそのまま本番の分類に使える状態ではありません。
まず歩行・旋回・羽の動き・反射を含む非グルーミング例と、容器中央のグルーミング例を追加し、画像差分以外の特徴や学習が必要かを検証するための土台です。

## 開発用

専用venvのPythonから `grooming.py --video 元動画 --tracks tracks.csv --manual-session session.json --out 新しいフォルダ` で実行できます。
`--parameters JSONファイル` で測定パラメータを変更できます。出力に使用値が残り、既存結果を上書きしません。
同じラベルで調整と評価の両方を行った結果を、独立な評価精度として扱わないでください。
